## 🚀 What I'm building

### 🔐 [OpenWaymark](https://github.com/jagottsicher/OpenWaymark)

**A federated, post-quantum-secure protocol for verifiable supply-chain provenance.**

OpenWaymark is an attempt to answer a surprisingly difficult question:

> **Can we prove where something came from without trusting a blockchain, a central authority, or somebody's database?**

It combines cryptographic signatures, append-only Merkle logs, independently verifiable proofs and federation — designed as an open protocol rather than another token or blockchain project.

**Go · Cryptography · Merkle Trees · Post-Quantum Security · Distributed Systems**

---

### 🖥️ [Breakthrough](https://github.com/jagottsicher/breakthrough)

**A powerful terminal-native file manager and workspace for Linux and POSIX systems.**

Breakthrough started with a simple idea:

> **The shell belongs inside the file manager — not beside it.**

It combines a full embedded Bash shell with a modern TUI, panels, dialogs, context menus and terminal-based workflows.

**Go · tcell · tview · TUI · POSIX · Terminal Engineering**
